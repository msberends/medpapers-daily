What are folders for?

Folders let you organise papers you want to keep — for instance by project, grant, or topic you're actively working on.

Once a paper is in a folder it stays there regardless of read or star status, so folders work well as a personal reference library alongside the inbox-style unread view.

To add a paper to a folder, open it and use the Move control, or select multiple papers in the feed and use the bulk action bar. Folders appear in the sidebar of the feed so you can filter to just those papers at any time.
