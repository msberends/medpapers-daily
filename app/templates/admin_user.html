How search profiles work

Each profile is a named PubMed query that runs on this user's fetch schedule. Papers returned by any active profile are added to the user's library, deduplicated by PubMed ID. You can configure as many profiles as needed and enable or disable them individually.

Writing a good query

  • Use [MeSH] to match controlled vocabulary terms: "Artificial Intelligence"[MeSH]
  • Combine terms with AND, OR, and NOT: ("machine learning"[MeSH] OR "deep learning") AND "clinical microbiology"
  • Search specific fields with tags: [tiab] for title and abstract, [au] for author, [jour] for journal
  • Phrase search with quotes: "antimicrobial resistance"

Use PubMed Advanced Search to build and test queries interactively before pasting them here.

Changes take effect on this user's next fetch run.

How topic classification works

PubMed assigns controlled vocabulary terms called MeSH headings (Medical Subject Headings) to every indexed paper. The topic map below translates those terms into the user's own category labels, which appear as coloured badges in their feed.

When a paper carries one or more MeSH terms that appear in the map, it receives the corresponding topic label. Multiple MeSH terms can map to the same label, and a paper can belong to more than one topic. Papers with no matching terms are shown as Unclassified.

To find the exact MeSH heading for a concept, use the NLM MeSH Browser. The term must match character-for-character, including capitalisation.

Topic labels are applied at display time and take effect immediately without re-fetching.
